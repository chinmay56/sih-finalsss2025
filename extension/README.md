# Floating Translator Extension

A cross-platform floating translator that stays on top of all applications.

## Quick Start

### Option 1: Auto Setup
```bash
python setup.py
```

### Option 2: Manual Setup

#### Windows
```cmd
pip install requests pyperclip Pillow
python floating_translator.py
```

#### macOS/Linux
```bash
pip3 install requests pyperclip Pillow
python3 floating_translator.py
```

## Features
- 🌐 Floating circular button
- 🎯 Always on top
- 🖱️ Drag to move anywhere
- ⚡ Instant translation
- 🏛️ Cultural design theme
- ⌨️ Keyboard shortcuts

## Keyboard Shortcuts
- `Ctrl+Enter`: Translate
- `Ctrl+C`: Copy result
- `Escape`: Minimize

## Requirements
- Python 3.7+
- tkinter (usually included)
- requests
- pyperclip
- Pillow

## Supported Languages
- English ↔ Nepali
- English ↔ Sinhala
